CAPTURAS PARA LA LANDING
========================

Coloca aquí las imágenes con estos nombres exactos. No hace falta tocar el HTML:
en cuanto el archivo existe, la imagen sustituye al bloque "Captura pendiente".

Formato recomendado: PNG o WebP, 16:9, 1600x900 px (se recortan a 16:9 con object-fit).
Si usas WebP, cambia también la extensión en el src de index.html.

Archivo                     Tamaño      Dónde aparece
--------------------------  ----------  -----------------------------------------------
captura-hero.png            1600x900    Hero (vista principal del panel / Race Control)
captura-configuracion.png   1600x900    Bloque "Del formulario al archivo correcto" + galería
captura-entrylist.png       1600x900    Galería: Entry lists y administradores
captura-clima.png           1600x900    Galería: Clima y condiciones de sesión
captura-assists.png         1600x900    Galería: Físicas y ayudas a la conducción
captura-rotacion.png        1600x900    Bloque "Un calendario que se corre solo" + galería
captura-jugadores.png       1600x900    Bloque "La parrilla en tiempo real" + galería
captura-consola.png         1600x900    Galería: Consola del servidor en tiempo real
captura-historial.png       1600x900    Galería: Historial de carreras y récords
captura-acceso.png          1600x900    Galería: Acceso web protegido por token
                                        (ventana de ACC_AdminPanel.exe con el token ENMASCARADO)
og-image.png                1200x630    Vista previa al compartir (Open Graph / Twitter).
                                        No se muestra en la página.

Antes de publicar una captura:
- Oculta contraseñas, el token completo, Steam IDs y nombres de pilotos reales.
- Comprime las imágenes (por ejemplo con squoosh.app) para que pesen < 300 KB.
